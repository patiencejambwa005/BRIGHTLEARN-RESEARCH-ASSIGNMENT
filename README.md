## Foundations of Data Analytics and Data Science

This assignment is an introduction to the basic concepts of Data Analytics and Data Science.

The assignment covers important foundations that are useful for someone starting a journey in the data field. It focuses on understanding data, how data is collected and used, and some of the tools and technologies used by data professionals.
